## How to Compile and Run

To compile the C program, use:

```bash
gcc hello.c -o hello
```

To run the compiled program:

```bash
./hello
```

You can also use the following command on Linux/macOS:

```bash
gcc hello.c -o hello && ./hello
```

## Git Commands

The following Git commands can be used to save and upload changes to GitHub:

```bash
git add README.md
git commit -m "Update README with project details"
git push
```

### Explanation

* `git add README.md` — Adds the README file to the staging area.
* `git commit -m "Update README with project details"` — Saves the changes with a commit message.
* `git push` — Uploads the committed changes to the GitHub repository.
